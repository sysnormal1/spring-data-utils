This package contains utilities.

## 📦 Maven Dependency

Add the dependency below to your `pom.xml`:

```xml
<dependency>
    <groupId>io.github.sysnormal1.commons.spring</groupId>
    <artifactId>spring-data-utils</artifactId>
    <version>0.0.4</version>
</dependency>
```

## 🧬 Clone the repository

To get started locally:

```bash
git clone https://github.com/sysnormal1/spring-data-utils.git
```

## 🔧 Build and Local Test

```bash
mvn clean install
```
